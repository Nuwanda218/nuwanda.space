# 首页 v0.1 设计与实施

日期：2026-10-15。依据：用户提供的首页任务书及两张自有照片，已明确授权开发、本地验收和条件允许时安全上线。

## 设计

采用暖白背景、深灰绿文字、Georgia 大标题、细线分隔和无圆角摄影。顶部直接呈现 Explore/About，手机无需菜单脚本。文字严格沿用任务书。

两张原图逐字节移动到 `src/assets/photos/`：`2026元旦升旗.jpeg` → `new-year-flag-2026.jpeg`，`我和朋友们.jpg` → `friends.jpg`。首屏下方以升旗合影为大封面，桌面 8:5、焦点向下以保留队伍，手机展示完整竖幅；Explore 后采用双栏生活片段，朋友合影保留原始比例及水印。三条栏目入口保持纵向文字列表。Life/Timeline 页分别复用对应照片，仍明确为待整理栏目，不编造经历或文章。

共用 SiteLayout、Header、Footer 和维护导航的 site.ts。首页、About、三个栏目均 SSG；栏目 noindex，首页/About 可索引。保留 LocalLayout 与 SSR/API/SSG 验收路由；原首页浏览器按钮移到独立验收页。首页无客户端 JS，图片由 Astro Picture 输出 WebP/JPEG srcset，有固有尺寸，封面 eager/high，朋友图 lazy。基础 SEO、canonical、OG、favicon、robots/sitemap 一并实现。
