# 素材入口

你以后新增内容，只需要操作这个文件夹。完整说明见 [本机素材使用指南](../docs/素材区使用指南.md)。

- `life/`：生活记录，每条内容一个文件夹。
- `notes/`：学习笔记与文章，每篇一个文件夹。
- `guard/`：国旗护卫队记录，每个事件一个文件夹。
- `site/profile.json`：个人介绍与关键词。
- `_templates/`：可以直接复制的三个空白模板，不会显示在网站上。

每条内容文件夹内放一个 **index.md**（正文），照片直接放在旁边。系统自动发现记录与照片，不用修改页面、import 或列表。

最简单的例子：

```text
life/
└─ 2026-10-18-秋日散步/
   ├─ index.md
   ├─ 树下的落叶.jpg
   └─ 路边的长椅.jpg
```

`index.md` 可以只有一句话：

```markdown
今天走了一条平时很少经过的小路，树叶已经开始变黄。
```

日期和标题从文件夹名称自动识别。没有日期也可以；没有提供的日期不会被编造。开发服务运行时保存后自动更新；生产预览需重新构建。换配色、网格、字体与排列规则时由展示层处理，这里的正文和原图不需要移动。
